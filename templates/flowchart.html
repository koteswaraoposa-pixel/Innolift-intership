How the website works

Flowchart

Authentication → Prediction → Records. Use this as a guided walkthrough for the complete app behavior.

Flow Diagram

@startuml
skinparam backgroundColor transparent
skinparam shadowing false

start
:Open Home URL (/);
if (Authenticated?) then (Yes)
  :Show Dashboard (index.html);
else (No)
  :Redirect to /login;
endif

:Login or Sign up;
if (Signup?) then (Yes)
  :POST /register; create user in SQLite;
endif
:POST /login; verify password hash;

:Redirect to the originally requested page;

if (Route is /predict?) then (Yes)
  :Show Prediction Form (register.html);
  :POST /predict with borrower inputs;
  :Run ML model (final_model.pkl) OR fallback scorer;
  :Save record to SQLite (LoanPredictions);
  :Render premium result (loan_prediction.html);
else (No)
  if (Route is /predictions?) then (Yes)
    :Query LoanPredictions;
    :Render records table (students.html);
  endif
endif

:User may Logout;
:GET /logout; clear session;
stop
@enduml
