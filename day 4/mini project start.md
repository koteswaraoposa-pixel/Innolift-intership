# Project Name:

# Loan Default Risk Prediction

# ------------------------------------------------------------

# Dataset

# ------------------------------------------------------------

# Dataset Name:

# Loan_Default.csv

# Description:

# This dataset contains information about loan applicants,

# their financial background, credit history, property

# details, loan characteristics, and repayment status.

# The dataset is useful for machine learning because it

# contains historical records that can be used to identify

# patterns associated with loan default risk.

# Financial institutions can use these patterns to assess

# whether a new applicant is likely to default on a loan.

# ------------------------------------------------------------

# Features (X Columns)

# ------------------------------------------------------------

# The following input features will be used to train

# the machine learning model:

# 1. loan_amount

# - Total loan amount requested by the customer.

# 2. income

# - Annual income of the applicant.

# 3. Credit_Score

# - Creditworthiness score of the customer.

# 4. LTV (Loan-To-Value Ratio)

# - Ratio of loan amount to property value.

# 5. property_value

# - Estimated value of the property.

# 6. rate_of_interest

# - Interest rate applied to the loan.

# 7. term

# - Loan repayment duration.

# 8. dtir1

# - Debt-To-Income Ratio.

# These features were selected because they have a direct

# impact on the applicant's ability to repay the loan and

# therefore influence loan default risk.

# ------------------------------------------------------------

# Target Variable (Y Column)

# ------------------------------------------------------------

# Target Column:

# Status

# Description:

# Status represents whether a customer defaulted on the loan.

# 0 = No Default

# 1 = Default

# The objective of the model is to predict the loan status

# using the selected financial and loan-related features.

# ------------------------------------------------------------

# Problem Statement

# ------------------------------------------------------------

# Banks and financial institutions face significant losses

# when borrowers fail to repay loans.

# Traditional risk assessment methods may not accurately

# identify high-risk applicants.

# This project aims to develop a Machine Learning model

# that predicts loan default risk using customer financial

# information, credit scores, and loan characteristics.

# ------------------------------------------------------------

# Question the Model Will Answer

# ------------------------------------------------------------

# "Based on the applicant's income, credit score,

# loan amount, property value, debt-to-income ratio,

# and other financial indicators, is the customer

# likely to default on the loan?"

# ------------------------------------------------------------

# Expected Outcome

# ------------------------------------------------------------

# The trained Machine Learning model will learn patterns

# from historical loan records and predict the probability

# of loan default for new applicants.

# The predictions can help organizations:

# - Reduce financial losses

# - Improve loan approval decisions

# - Identify high-risk borrowers

# - Enhance credit risk management

# - Improve customer assessment processes

# - Support data-driven lending decisions

# ------------------------------------------------------------

# Machine Learning Technique

# ------------------------------------------------------------

# Algorithm:

# Linear Regression

# Problem Type:

# Regression (Day 4 Requirement)

# Evaluation Metrics:

# - RMSE (Root Mean Squared Error)

# - R² Score
